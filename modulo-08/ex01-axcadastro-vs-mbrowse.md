a. Quando você usaria AxCadastro e quando usaria mBrowse ? Dê um exemplo de cada.
AxCadastro: Eu usaria quando precisasse fazer um cadastro normal do Protheus, tipo cadastrar clientes ou fornecedores.
Exemplo: Cadastro de clientes (SA1).

mBrowse: Eu usaria quando precisasse criar uma tela para consultar informações de um jeito mais personalizado.
Exemplo: Uma tela mostrando os pedidos com cores diferentes dependendo da situação.


b. Cite três coisas que o mBrowse faz e o AxCadastro não faz.

1. Coloca legendas com cores nos registros.
2. Permite criar botões personalizados.
3. Dá para fazer filtros e consultas mais específicas.

c. Na configuração de legendas ( aColors ), por que a regra ".T." deve ficar por último?

Porque .T. sempre é verdadeiro. Se ela ficar primeiro, todas as linhas vão usar essa regra e as outras nunca vão funcionar.

d. Qual a diferença entre um campo Virtual (X3_RELACAO) e um gatilho (SX7) para preencher
o nome do cliente?

O AxCadastro é mais para fazer um cadastro padrão, com incluir, alterar, excluir e consultar.

Já o mBrowse serve para montar uma tela de consulta mais personalizada, com filtros, cores, botões e outras funções que o AxCadastro não tem.
