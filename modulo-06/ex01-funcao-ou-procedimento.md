Exercício 1 — Função ou procedimento? (conceitual)

Para cada item abaixo, responda se é uma função (retorna um valor) ou um procedimento (só
executa uma ação) e justifique em uma frase:

Str() — Função
Justificativa: É uma função porque recebe um número e retorna esse número convertido para uma string.

QOut() — Procedimento
Justificativa: É um procedimento porque apenas exibe uma mensagem na tela, sem retornar um valor.

Date() — Função
Justificativa: É uma função porque retorna a data atual do sistema

Len() — Função
Justificativa: É uma função porque retorna a quantidade de caracteres de uma string ou de elementos de um array.

Upper() — Função
Justificativa: É uma função porque retorna a string convertida para letras maiúsculas.

ClearScreen() — Procedimento
Justificativa: É um procedimento porque apenas limpa a tela, sem retornar nenhum valor.
