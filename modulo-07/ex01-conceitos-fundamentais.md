a. Qual é a função do AppServer?
O AppServer é o servidor de aplicação do Protheus. Ele processa as rotinas do sistema, executa os programas em ADVPL, faz a comunicação com o banco de dados e atende às solicitações dos usuários conectados.

b. O que é o RPO?
O RPO (Repository) é o arquivo que armazena os programas compilados do Protheus, como rotinas padrão e personalizadas. O AppServer utiliza o RPO para executar as funcionalidades do sistema.

c. Para que serve o Configurador (SIGACFG)?
O Configurador (SIGACFG) é o módulo utilizado para administrar e configurar o ambiente Protheus. Nele é possível cadastrar usuários, definir permissões, criar tabelas, configurar parâmetros e realizar outras configurações do sistema.

d. Qual a diferença entre campo Real e campo Virtual no SX3?
O campo Real é gravado no banco de dados, armazenando permanentemente as informações da tabela. Já o campo Virtual não é salvo no banco, pois seu valor é calculado ou gerado apenas durante a execução do sistema.
